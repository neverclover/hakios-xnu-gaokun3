# gaokun3 on the newer generation (xnu-12377 / iOS 26 kernel)

The whole story is in the porting report (sections 6bm to 6br, Chinese:
`gaokun3-porting-report.zh.md`). The short version, for anyone who wants to
rebuild what this machine builds today without a Mac:

    # 1. the Apple tag
    git clone https://github.com/Apple-OpenSource/xnu  (or the tarball xnu-12377.121.6)
    # 2. the HakiOS-for-26 patch of superboyyy/hakios-arm64e-dada
    cd hakios-arm64e-dada && kernel/apply.sh        # makes the patched tree
    # 3. our bring-up: 226 lines, plain arm64 on Linux, no iig, no Apple clang
    git apply docs/devices/gaokun3-12377-linux-bringup.patch
    # 4. the borrowed SDK moved to 26.1 (joseluisq/macosx-sdks) - see base/xnu-deps/setup.sh there

The build runs with the same xnu-build.sh as this generation; `MACHINE=BCM2837`
with `RC_DARWIN_KERNEL_VERSION=12377.121.6`. What it produces has been booted
on the real MateBook by this loader (the payload-next.bin mechanism,
`docs/devices/gaokun3.md`): the 26-generation kernel runs its desktop stack on
the hardware for ~100 seconds in its first tries and is being walked forward
one failure at a time (single-core bring-up variant, reporting board, the
loader's own failure counter).
